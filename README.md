# Push-Ups
A simple WebApp page that counts a user push ups to reach the prompted goal, built with my signutre color design as part of my "Portfolio Project (Pj)"
This WebApp built by using TensorFlow.js with MoveNet detection model.

Goal prompt: The page asks for user prompt for specific amount of push-ups to set as the goal/target (max 500 not possible unless you are an alien :P).
Display and goal: The page shoes count/target, along with a progress bar that filled as much as the user specified while the prompt alert showed up.
Counting: Behind the hood i added a CONFIG area in the script.js file that is used to adjust the sensitivity, elbows/shoulder/wrist degree so the camera will see the best.
Camera window: In the middle of the page you will encounter a black square screen (*resized mostley for phone users*) that will preview the camera and the model will sensor the skeleton to keep track of your body.
